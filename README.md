# Caesar Cipher Project (Python)

A simple Python program that encodes and decodes messages using the Caesar Cipher technique. This project was built as part of my Python learning journey.

---

## What is a Caesar Cipher?

A Caesar Cipher is one of the simplest encryption techniques. It works by shifting each letter in a message by a fixed number of positions in the alphabet.

For example:
- A shift of 1 turns `a` → `b`
- A shift of 3 turns `a` → `d`

---

## How the program works

The user can choose to:
- **Encode** a message (encrypt it)
- **Decode** a message (decrypt it)

The program then:
1. Takes user input (message, shift value, and direction)
2. Shifts each letter in the alphabet
3. Returns the encoded or decoded message

---

## Features

- Encode and decode messages
- Continuous loop allowing multiple runs
- Modular function-based structure
- Simple command-line interface
